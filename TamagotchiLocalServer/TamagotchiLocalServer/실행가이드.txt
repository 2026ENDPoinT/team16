[다마고치 프로젝트 - FastAPI 로컬 서버 실행가이드]

1. 준비
   - Python 3.10 이상 설치
   - VS Code에서 TamagotchiLocalServer 폴더 열기
   - 터미널 열기 (PowerShell)

2. 최초 설치 (프로젝트 폴더에서 실행)
   py --version
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

3. 서버 실행
   .\.venv\Scripts\python.exe run_server.py

4. 실행 확인
   브라우저: http://127.0.0.1:8000/api/v1/health
   기대 출력: {"status":"ok"}
   API 테스트 화면: http://127.0.0.1:8000/docs

5. Unity A / Unity B 통신 시연
   서버를 끄지 말고 새로운 터미널을 열기
   .\.venv\Scripts\python.exe examples\demo_client.py

6. 자동 테스트
   .\.venv\Scripts\python.exe -m pytest -q

7. 서버 중지
   서버 실행 터미널에서 Ctrl + C

8. 중요 사항
   - 127.0.0.1은 자기 컴퓨터를 의미함 (다른 PC에서는 접속 불가)
   - 프로젝트 최상위 폴더에서 명령어를 실행해야 함
   - 서버를 실행하면 data/tamagotchi.db (SQLite) 파일 생성
   - SQLite 파일은 서버를 종료해도 유지됨
   - 서버에는 아직 인증 기능이 없음: 실제 비밀번호/개인정보를 저장하지 말 것
   - 통신 규격: docs/API_SPEC.md 참고
   - 파일별 역할 및 수정 위치: docs/ARCHITECTURE.md 참고

9. 흔한 오류
   [py 명령어를 찾을 수 없음]
      Python을 설치하고 터미널을 다시 실행하기
   [ModuleNotFoundError]
      2번 명령어로 필요한 패키지가 설치됐는지 확인하기
   [Port 8000 is already in use]
      이미 실행된 서버를 Ctrl+C로 종료하거나 .env에서 APP_PORT 변경하기
   [localhost 연결 실패]
      3번 서버가 실행 중인지, 주소/포트가 일치하는지 확인하기
   [Windows 애플리케이션 제어 정책 차단]
      보안 기능을 무조건 해제하지 말고 Python 출처/차단된 실행 파일을 먼저 확인하기
